# Speech Tail Asset Source

The three white comic speech-tail PNGs in this folder are static derivative/adaptation assets
created for the BattleRework UI using public-domain / CC0 speech-bubble references.

Primary visual reference:
- Wikimedia Commons: "Speech bubble white.svg"
- Author: Amada44
- License: CC0 1.0 Universal / Public Domain dedication
- Source page: https://commons.wikimedia.org/wiki/File:Speech_bubble_white.svg

Additional public-domain reference:
- Wikimedia Commons: "Speech balloon.svg"
- Public domain
- Source page: https://commons.wikimedia.org/wiki/File:Speech_balloon.svg

Local assets intentionally remove the black tail outline and keep only a white comic tail body
so it can overlap the existing white speech-bubble face without a visible seam.
