# 0015 후속 확인 기록

상태: 미완료 — Unity 실행 검증 대기.

Unity가 설치되지 않아 BattleScene 재현, 컴파일 및 실행 검증은 수행하지 않았다. 재현하여 확인된 결함만 수정한다는 조건에 따라 이전 시도의 BattleSpriteShadow.cs 변경을 철회했다. 현재 이 작업으로 적용한 런타임 코드 변경은 없다. 아래 코드 경로 확인은 실행 검증 결과가 아니다.

| 항목 | 코드 확인 및 원인 | 수정 파일 | Unity 확인 결과 |
| --- | --- | --- | --- |
| 전투 밖 암부 잔류 | BattleCombatCornerVignetteController.Update는 비전투 시 currentBlend를 0으로 수렴시킨다. ApplyVisual은 저체력·피격 강도에도 currentBlend를 곱하며, OnDisable은 즉시 해제한다. 잔류 결함은 재현하지 못해 수정하지 않았다. | 없음 | 미실행 |
| 접지 캐릭터 발과 투영 그림자 분리 | 최초 캡처 위치와 현재 프레임 알파 하단의 차이를 결함 후보로 추론했으나, 실제 분리·튀는 현상은 재현하지 못했다. 발 위치 갱신 조건 변경을 철회하고 수정을 보류한다. | 없음; 이전 시도의 BattleSpriteShadow.cs 변경 철회 | 미실행; 결함 여부·수정 필요성 미확인 |
| 과도한 겹침 | 실제 겹침의 정도를 재현하지 못해 수정하지 않았다. | 없음 | 미실행 |
| 중앙·가장자리·모서리 밝기 | 셰이더 수식만 확인했다. 같은 BattleScene 화면에서 비네트 전후를 비교하지 못했으므로 완료 기준 충족을 판단할 수 없다. | 없음 | 미실행; 밝기 비교 미검증 |
| 전투 종료 후 해제 | 코드에 해제 경로가 있으나 실제 전투 종료 시 동작은 확인하지 못했다. | 없음 | 미실행; 해제 여부 미검증 |
| HUD 가독성과 기존 저체력 연출 | 비네트 전후 및 저체력 상태에서 화면을 확인하지 못했다. | 없음 | 미실행; 가독성·기존 연출 유지 미검증 |

기존 투영·접촉 모드, 방향·길이·농도 및 조명 설정은 변경하지 않았다. 재현되지 않은 항목을 정상 또는 검증 완료로 판정하지 않는다.

Unity 실행 환경에서 다음 결과를 기록해야 작업을 완료할 수 있다. 아직 수행한 항목은 없다.

1. BattleScene에서 비네트 활성·비활성의 동일 장면을 비교하여 중앙 보존과 가장자리보다 어두운 모서리를 확인한다.
2. 정상 체력·저체력 각각에서 전투를 종료하고 페이드 해제, HUD 가독성 및 기존 저체력 연출 유지를 확인한다.
3. 이동·좌우 반전·애니메이션 및 점프 전후에 발 연결을 확인한다. 분리·튀는 현상이 재현되면 대상, 프레임, 재현 절차를 기록하고 그때 최소 수정 후 동일 절차로 전후를 비교한다.
4. 여러 캐릭터가 모인 장면에서 과도한 겹침을 확인한다. 재현된 경우에만 원인 확인과 수정을 진행한다.
